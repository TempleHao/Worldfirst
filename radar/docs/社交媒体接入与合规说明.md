# WorldFirst Radar｜社交媒体接入与合规说明

更新时间：2026-10-25。范围：万里汇、空中云汇、派安盈、XTransfer、连连国际、PingPong、珊瑚跨境、寻汇、Skyee。

## 核心区别

1. **发现**：Google News 等公开搜索索引发现平台页面链接/标题，不能保证全量、实时或仍可访问正文。
2. **内容采集**：经平台授权的 API 或具有明确授权与数据使用范围的数据供应商，允许读取约定内容/摘要。
3. **传播指标**：阅读、点赞、评论、转发、真实发布时间、作者关系必须来自具有字段合法使用权的实际接口。不可从索引命中数推算。
4. **业务判断**：机器对标题/摘要作初筛，指控仅列为待核验，不自动宣称品牌发生危机。

## 实现

| 渠道 | 当前可运行功能 | 进一步授权后的能力 | 已知限制 |
| --- | --- | --- | --- |
| 微信公众号 | 搜索引擎可索引的公开链接线索（可能为0条） | 自家公众号后台数据或签约公众号舆情服务 | 自有公众号数据不等于全网公众号；未提供可信的通用全网搜索 API |
| 小红书 | 公开索引线索 | 经授权供应商笔记与互动数据 | [官方Scope](https://openaccount.xiaohongshu.com/docs/scope) `read_notes` 尚标注规划中 |
| 抖音 | 公开索引线索 | 自有品牌关键字视频/评论管理；其他数据经许可 | [与我相关视频搜索](https://open.douyin.com/platform/resource/docs/ability/search-management/video/)不许竞品词，搜索能力另需申请 |
| 知乎 | 公开索引线索 | 配置密钥后尝试[知乎官方搜索API](https://developer.zhihu.com/) | API 数据结构和可用量需持实际密钥验收；有请求频率和计费要求 |

## 采集接口

`radar/scripts/social.py`：公开索引搜索、可选知乎官方API、第三方授权数据文件导入。
`radar/data/articles.json`：统一文章结构，`channel`、`discovery_method`、`rights`、`coverage`、`date_basis`、`metrics`。
`radar/data/social-status.json`：逐平台索引请求成功数、匹配数、官方API连接状态、供应商导入结果。

可用时长取决于站点收录与 API 配额。目前公开索引**不应称作“实时抓取平台全部内容”**。

### 知乎 API

官方公布端点：`GET https://developer.zhihu.com/api/v1/content/zhihu_search?Query=关键词`。需授权密钥（`ZHIHU_ACCESS_SECRET`），HTTP Bearer 和 `X-Request-Timestamp`。在仓库 Settings > Secrets and variables > Actions 新建密钥名即可；**不要把密钥提交到代码仓库或发到聊天里**。

代码已预留接入与结构化校验，但没有密钥，因此尚未证明官方API返回的字段兼容；不应宣称“知乎已成功接通”。

### 外部合法数据供应商

可从[新榜声量通](https://voice.newrank.cn/)等供应商询价并明确要求：覆盖品牌与竞品、原始内容链接、内容时间、平台、作者、评论、互动指标、商用存储与网页展示授权、API/SLA 和历史回溯范围。官网公开介绍定制API，但具体接口合同尚未获得。

经授权后，可将规范化 JSON 放入 `radar/inbound/licensed-social.json`（默认不存在）。示例：

```json
{
  "rights_confirmed": true,
  "permitted_to_display_excerpt": true,
  "items": [
    {
      "platform": "zhihu",
      "company": "worldfirst",
      "title": "万里汇使用体验反馈",
      "url": "https://www.zhihu.com/question/example",
      "published_at": "2026-10-20",
      "excerpt": "取得许可的数据摘要",
      "publisher": "已授权内容发布者",
      "engagement": {"likes": 5, "comments": 2},
      "observed_at": "2026-10-21T08:00:00Z"
    }
  ]
}
```

**以上示例仅供格式说明，不是实际舆情记录。** 任何未取得原始数据授权、展示权的内容不应输入该适配器；公开仓库不建议存储可能受许可限制的完整社媒数据。正式生产应走受控服务端数据库／API，且遵守最小必要展示和保留期限。

## 舆情分析为什么必需

对品牌方，真正的价值是：知道负面涉及资金安全还是普通费率抱怨、是单一投诉还是跨平台传播、是否出现商家选择迁移、何时启动危机响应。

应分别显示：
- **立场**：正面、中性、负面、混合、待研判。只用标题时置信度较低。
- **业务实质**：资金与账户、数据安全、监管、服务故障、客户体验。
- **传播**：已确认的不同发布方/平台；真实互动量仅在取得许可数据后展示。
- **是否人工确认**：未证实指控不可自动认定为既有事实。

算法参照 [DBS 年报](https://www.dbs.com/iwov-resources/images/investors/annual-report/dbs-annual-report-2025.pdf)、[巴塞尔SRP30](https://www.bis.org/basel_framework/chapter/SRP/30.htm) 和 [AMEC](https://amecorg.com/amecframework/) 的声誉风险管理与传播评估理念；本项目阈值并非这些组织发布的官方模型。

## 下一步验收

要宣布一个平台“已接入”，至少需要连续取得5个以上由该平台实际发布、能访问原文的真实新记录，对时间、品牌、重复率、正文/摘要、互动字段、使用许可逐项验证，再进行至少7天连续运行测试。仅返回 HTTP 200、无结果或搜索索引有命中都不算生产级接入。
